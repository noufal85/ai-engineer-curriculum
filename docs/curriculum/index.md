# Curriculum

Nine modules, sequenced. Shared core (0–6), the FDE differentiator (7), and capstones (8). **Every module is anchored by a build** — you run the app first, then the page explains what it does and the concept underneath.

Each module page:

- **🔨 The build** — the app to run (Dockerized). Start here.
- **What it teaches** — the concept, explained *through* the build. Reference, not a lecture.
- **Checklist** — ticks when the build runs and you can defend the tradeoff. Mirrored on [Progress](../progress.md).

All build code lives in [`builds/`](https://github.com/noufal85/ai-engineer-curriculum/tree/main/builds), one Dockerized folder per build.

Start at [Module 0 · Foundations](00-foundations.md) and its build, [`00-hello-llm`](https://github.com/noufal85/ai-engineer-curriculum/tree/main/builds/00-hello-llm).
